# Airbus-OEM-Files
## Folders:
* `Deutsch-Connectors`:  3D models for some Deutsch Connectors found in OEM Airbus panels
* `TRIM_MOTOR`: 3D model Pedestal Trim Motor
* `ARINC 429`: Experiments with ARINC 429
